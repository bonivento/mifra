# Mi Fragancia – sitio web

Sitio estático (Inicio + Contacto) generado desde las pantallas de Stitch.

- `npm install && npm run build` regenera `index.html`, `contacto.html` y `assets/styles.css` (Tailwind compilado, sin CDN).
- `npm start` sirve el sitio en http://localhost:8080.
- Edita `src/stitch-*.html` + `build.py` (o los HTML generados directamente si prefieres).
- El formulario de contacto abre WhatsApp con el mensaje armado (`assets/site.js`).

**Pendiente de confirmar:** teléfono/WhatsApp (`573104567890`), correos, horarios y precios son datos de ejemplo de Stitch. Las fotos de producto se reemplazaron por iconos; agrega fotos reales en `assets/`.
